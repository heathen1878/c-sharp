# Conditionals

if / else

```c#
if (condition) 
{
    execute_if_true
}
else if (condition)
{
    execute_if_true
}
else
{
    execute
}
```

switch / case and

```c#
switch (condition)
{
    case condition_match {
        execute
        break;
    }
    default 
    {
        break;
    }
}
```

conditional 

```c#
a ? b : c
```
